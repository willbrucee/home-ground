Every picture the game will show. Red-framed ones are low-confidence picks worth a look; grey ones are in the reserve (no usable picture, so they're out of the game). To change one, add it to data/images.json, e.g. "wd-Q615": { "use": "Better file.jpg" }, { "reject": ["Bad file.jpg"] } or { "none": true }, then run python3 scripts/pick_images.py. Or press Reject on any picture, then Save rejections: it adds them to data/images.json for you (Chrome and Edge write the file directly; other browsers download the merged file). Faces are marked where the crop will centre.
