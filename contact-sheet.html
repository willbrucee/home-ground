Contact sheet

Every picture the game will show, the weakest first. For athletes you see the whole photo with the face the checks found (gold box), the crop the question card will show, and the numbers: face height as a share of the picture (needs 18%+), face width in the 1,280 px file the game loads (120+), sharpness of the face on the 500 px copy (20+), eye-white brightness against the skin (1.0+) and how far the face is turned. Numbers close to the limit are in red. Red-framed ones are low-confidence picks worth a look; grey ones are in the reserve (no usable picture, so they're out of the game). To change one, add it to data/images.json, e.g. "wd-Q615": { "use": "Better file.jpg" }, { "reject": ["Bad file.jpg"] } or { "none": true }, then run python3 scripts/pick_images.py. Or press Reject on any picture, then Save rejections: it adds them to data/images.json for you (Chrome and Edge write the file directly; other browsers download the merged file). Faces are marked where the crop will centre.
